## ✨ Features

* **Motion Intro Loader:** Animated intro screen transition before entering the main portfolio.
* **Godly-Inspired Design:** Dark, modern, minimalist UI using Tailwind CSS with glassmorphism effects.
* **Interactive Terminal CLI:** Integrated command-line drawer with executable custom commands (`help`, `about`, `skills`, `projects`, `clear`).
* **Interactive Canvas Background:** Dynamic particle grid effect powered by HTML5 Canvas.
* **Zero Build Dependencies:** Built into a single lightweight `index.html` file using CDN-hosted utilities—no `node_modules` or build step required.

---

## 🛠️ Built With

* **Markup & Structure:** HTML5
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (via CDN) & Custom CSS Keyframe Animations
* **Interactivity:** Native JavaScript (ES6+) & Web Audio API
* **Icons & Fonts:** [Lucide Icons](https://lucide.dev/) & [Google Fonts](https://fonts.google.com/) (Space Grotesk & JetBrains Mono)
